🎮 Что такое Lolka?

Lolka — российская платформа для общения в реальном времени, созданная как аналог Discord. Серверы с текстовыми и голосовыми каналами, роли, трансляции экрана (до 5 одновременно), ЛС и групповые чаты. Работает без VPN на всех популярных платформах.

HD-трансляции

До 1440p 60fps, до 5 стримов одновременно

Серверы и роли

До 250 000 участников, 500 каналов, 250 ролей

API для ботов

Библиотеки lolka.py и lolka.js для разработчиков

Импорт из Discord

Перенос ролей и структуры каналов

Все платформы

Windows, macOS, Linux, Android, iOS и браузер

Без VPN

Стабильная работа на территории России

Что умеет бот

Полный набор инструментов для комфортного общения на сервере

Модерация

Кик, мут, очистка чата — базовые инструменты для поддержания порядка на сервере.

Утилиты

Карточка пользователя, аватар, отладка — вся информация под рукой одной командой.

Конфигурация

Свой префикс, канал приветствий, канал логов и авто-роль — настраивается прямо в чате.

Умное меню

Интерактивный /команды со всеми командами, сгруппированными по категориям.

Быстрый

Написан на современном Python с асинхронной библиотекой. Отвечает мгновенно.

Безопасный

Токен хранится в .env, права проверяются на каждой команде.

Команды бота

Нажми на команду, чтобы скопировать её в буфер обмена

🟢 Основное 4

  • /ping Проверка связи (pong 🏓)
  • /hello Приветствие пользователяАлиасы: !hi, !привет
  • /info Информация о боте (пинг, аптайм, сервер, канал)
  • /latency Задержка бота в миллисекундах

👤 Пользователи 3

  • /user [@user] Карточка пользователя (имя, ID, роли, статус, даты)Алиасы: !u, !юзер
  • /avatar [@user] Показать аватарАлиасы: !av, !аватар
  • /debug_user [@user] Отладка: список атрибутов (скрыта из меню)

🛡️ Модерация 3

  • /purge [число] Удалить N сообщений (1–100)Алиасы: !clear, !очистить · Права: Manage Messages
  • /kick @user [причина] Кикнуть участникаАлиасы: !кик · Права: Kick Members
  • /mute @user [время] Заглушить (в разработке)Алиасы: !мут · Права: Manage Roles

⚙️ Конфигурация 5

  • /конфиг Показать текущие настройки сервераАлиасы: !config · Только администратор
  • /конфиг префикс [символ] Изменить префикс (до 5 символов)Алиасы: !конфиг prefix
  • /конфиг приветствие [#канал] Установить канал приветствийАлиасы: !конфиг welcome
  • /конфиг лог [#канал] Установить канал логовАлиасы: !конфиг log
  • /конфиг роль [@Роль] Авто-роль новым участникамАлиасы: !конфиг autorole

📖 Справка 1

  • /команды Список всех команд с группировкой по категориямАлиасы: !помощь, !help, !h
