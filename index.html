Что умеет бот

🛡️

Модерация

Кик, бан, мут, очистка чата, предупреждения. Полный контроль над порядком на сервере.

🎲

Развлечения

Монетка, кубик, магический шар, камень-ножницы-бумага и случайные шутки — чтобы чат не скучал.

🔧

Утилиты

Информация о пользователях, аватары, серверная статистика — всё под рукой одной командой.

📖

Умное меню

Интерактивный !help с кнопками. Все команды разложены по категориям — не запутаешься.

⚡

Быстрый

Написан на современном Python с асинхронной библиотекой. Отвечает мгновенно.

🔒

Безопасный

Токен хранится в .env, права проверяются на каждой команде.

Команды бота

🎲 Развлечения

  • !coinflipПодбросить монетку
  • !roll [число]Бросить кубик с N сторонами
  • !8ball [вопрос]Магический шар ответит на вопрос
  • !choose [варианты]Выбрать один из вариантов
  • !jokeСлучайная шутка
  • !rps [камень/ножницы/бумага]Камень-ножницы-бумага с ботом

🛡️ Модерация

  • !kick @user [причина]Выгнать участника с сервера
  • !ban @user [причина]Забанить участника
  • !unban [ID]Разбанить по ID
  • !mute @user [минуты]Замьютить на время
  • !unmute @userСнять мут
  • !clear [число]Удалить N сообщений
  • !warn @user [причина]Выдать предупреждение

🔧 Утилиты

  • !userinfo [@user]Информация о пользователе
  • !helpИнтерактивное меню команд
