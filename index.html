Как добавить Юрику на сервер

Установка занимает меньше минуты. Юрика работает через платформу Lolka.

  1. Открой страницу установки по кнопке ниже.
  2. Войди в свой аккаунт Lolka.
  3. Выбери сервер, куда хочешь добавить Yurika Bot.
  4. Проверь разрешения: сообщения, роли, каналы, модерация, вебхуки.
  5. Нажми «Авторизовать».
  6. Напиши @Yurika_Bot — она ответит.
